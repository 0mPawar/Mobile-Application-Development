## 📖 About This Repository

This repository contains the practical programs and projects developed for the **Mobile Application Development (MAD)** subject.
All applications are developed using **Android Studio** and written in **Java / Kotlin** with **XML layouts**.

---

## 🛠 Technologies Used

* Android Studio
* Java / Kotlin
* XML Layouts
* Android SDK

---

## 📂 Practicals Included

The repository contains implementations of various Android concepts such as:

* User Interface Design
* Event Handling
* Layouts (**LinearLayout, ConstraintLayout, GridLayout**)
* CheckBox and RadioButton
* Calculator Application
* Progress Bar Implementation
* Intent and Activity Navigation

---

## ▶ How to Run the Project

1. Install **Android Studio**.
2. Clone this repository or download the ZIP file.
3. Open the project in Android Studio.
4. Build and run the application on an emulator or Android device.
